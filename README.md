# Анализ воронки интернет-магазина

Учебный проект по событиям интернет-магазина. Здесь рассчитана пользовательская
воронка, дневная динамика и проверены две продуктовые гипотезы.

## Данные

Используется полный файл `events.csv` из
[Retailrocket Recommender System Dataset](https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset).

Скачайте архив со страницы датасета, извлеките `events.csv` и положите его в
`data/raw/events.csv`. Этот файл не добавляется в Git. Автоматической замены
полного датасета на тестовую выборку нет.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
python scripts/run_analysis.py
```

Скрипт сохраняет таблицы, графики и `reports/results.json`.

## Воронка

Для каждого пользователя берутся:

1. первый просмотр;
2. первое добавление в корзину после просмотра;
3. первая покупка после корзины.

Этапы проверяются по времени, но не связываются по одному `itemid`.

После удаления 460 полных дубликатов осталось 2 755 641 событие и 1 407 580
уникальных пользователей. Период данных: с 3 мая по 18 сентября 2015 года.

| Этап | Пользователи | Конверсия от просмотра |
|---|---:|---:|
| Просмотр | 1 404 179 | 100,000% |
| Корзина | 32 934 | 2,345% |
| Покупка | 9 952 | 0,709% |

Конверсия из корзины в покупку составила 30,218%. До корзины потеряно
1 371 245 пользователей, после корзины — 22 982. Медианное время от корзины до
покупки равно 0,10 часа. 95,549% покупок после корзины совершены в течение
24 часов.

## Гипотеза 1: выходные

Гипотеза: пользователи, впервые пришедшие в выходные, конвертируются в покупку
чаще, потому что у них может быть больше свободного времени.

| Первый просмотр | Пользователи | Покупатели | Конверсия |
|---|---:|---:|---:|
| Будни | 1 066 516 | 8 078 | 0,757% |
| Выходные | 337 663 | 1 874 | 0,555% |

Первая гипотеза не подтвердилась: в выходные конверсия оказалась ниже на
0,202 процентного пункта.

Для таблицы «будни/выходные × купил/не купил» минимальная ожидаемая частота
равна 2 393,2. Критерий хи-квадрат показал различие между группами:
χ² = 149,05, p-value = 2,80e-34. Направление различия оказалось противоположным
исходному ожиданию.

## Гипотеза 2: вечер

Гипотеза: пользователи, впервые пришедшие вечером, конвертируются в покупку
чаще, потому что вечером у них больше времени на выбор товара.

| Время первого просмотра | Пользователи | Покупатели | Конверсия |
|---|---:|---:|---:|
| Ночь | 440 608 | 2 851 | 0,647% |
| Утро | 109 007 | 586 | 0,538% |
| День | 323 011 | 2 533 | 0,784% |
| Вечер | 531 553 | 3 982 | 0,749% |

Вторая гипотеза тоже не подтвердилась: максимальная конверсия наблюдалась днём,
а не вечером.

Для таблицы «часть суток × купил/не купил» минимальная ожидаемая частота равна
772,6. Критерий хи-квадрат показал общую связь между временем первого просмотра
и покупкой: χ² = 107,64, p-value = 3,53e-23. По этим данным нельзя утверждать,
что именно время суток стало причиной различий.

## Графики

В `reports/figures/` сохранены:

- количество событий каждого типа;
- пользовательская воронка;
- активные пользователи по дням;
- события по дням;
- конверсия по дням первого просмотра;
- конверсия в будни и выходные;
- конверсия по четырём частям суток;
- распределение времени от корзины до покупки.

## Ограничения

- Часовой пояс timestamp неизвестен.
- Воронка не связывает этапы по одному товару.
- Данные наблюдательные и не доказывают причинность.
- У пользователей, пришедших ближе к концу датасета, было меньше времени на покупку.
- В данных нет цены, канала привлечения и информации о наличии товара.
